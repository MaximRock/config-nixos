# Disk usage — desktop widget (Noctalia)

Плагин `max/disk` для Noctalia (niri): плавающий виджет на столе со статистикой
корневого раздела `/` — процент занятого места, прогресс-бар, объёмы и график
истории загрузки за последние 30 минут.

## Что показывает

| Элемент | Значение |
|---|---|
| `/ 61%` | занято в процентах (обновление каждые 10 сек) |
| прогресс-бар | доля занятого места |
| `Занято 132 GiB · Свободно 74 GiB` | used = total−free, free = available |
| график | история каждые 10 сек, окно 180 точек = 30 мин (хранится в памяти, сбрасывается при рестарте Noctalia) |

## Устройство

- `plugin.toml` — манифест, `plugin_api = 16`, entry `root` → `desktop.luau`
- `desktop.luau` — раз в 10 с берёт `noctalia.diskStats("/")`, пишет историю и рендерит `ui.*`-дерево
- Цвета — роль `primary` из темы (меняется вместе с палитрой)

## Перемещение виджета по столу (редактор)

```sh
noctalia msg desktop-widgets-edit    # открыть редактор
noctalia msg desktop-widgets-exit    # закрыть (или кнопка Done)
```

- Открыть на **пустом workspace** (видна сетка).
- Перетаскивать виджет мышью; `Shift+drag` — без привязки к сетке, `G` — вкл/выкл сетку (шаг 16 px).
- Позиция пишется в `~/.local/state/noctalia/settings.toml` и перекрывает базовые
  `cx/cy` из репозитория `settings.toml`. Синхронизировать их в репо после перемещения.

## Диагностика

```sh
noctalia plugins list | grep max/disk
noctalia plugins lint modules/home/wm/niri/noctalia/plugins/disk
tail ~/.cache/noctalia/noctalia.log
```

Шейдер графика рисует линию только от 4 сэмплов — скрипт дописывает историю
дубликатами до 4 точек, поэтому график виден сразу после старта.
