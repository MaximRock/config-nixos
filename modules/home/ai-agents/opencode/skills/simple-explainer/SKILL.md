# Simple Explainer

## Когда использовать
Только по явной просьбе: «объясни просто», «простыми словами», «что это значит», ELI5.

## Как объяснять
- По-русски, без жаргона. Термин неизбежен — расшифруй тут же.
- Структура: суть одним абзацем → аналогия из жизни → пример → детали (только если просили).
- Одна мысль — одно предложение. Коротко, без воды.
- В ответе только объяснение, без лишних команд и файлов.
